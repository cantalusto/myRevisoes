📖 Medidas de Tendência Central

São ferramentas da estatística descritiva que indicam o ponto central ou a localização típica de um conjunto de dados. Resumem um grande volume de valores em um único número que representa o "centro" dos dados.

São três:

Aritmética ou Ponderada

Valor do meio

Valor mais frequente

➗ Média

Medida estatística que representa, de forma resumida, um valor central ou típico de um conjunto. É como um "ponto de equilíbrio". Frequentemente usada para identificar um padrão ou tendência geral.

Existem duas principais:

  • Média Aritmética — todos os valores têm o mesmo peso
  • Média Ponderada — cada valor tem um peso diferente

📐 Média Aritmética (x̄)

Soma de todos os valores dividida pelo número total de valores.
x̄ = Σxᵢ / n
Ex (Turma A): 3, 5, 6, 6, 6, 7, 8, 9, 10, 10
x̄ = (3+5+6+6+6+7+8+9+10+10) / 10 = 70/10 = 7,0
Ex (Turma B): 5, 5, 7, 7, 7, 7, 7, 7, 8, 10
x̄ = (5+5+7+7+7+7+7+7+8+10) / 10 = 70/10 = 7,0
⚠️ As duas turmas têm a mesma média (7,0) mas distribuições diferentes! Por isso a média sozinha não conta toda a história — sempre considere outras medidas.

⚖️ Média Ponderada (x̄ₚ)

Cada valor é multiplicado por um peso que representa sua importância relativa. Os pesos definem a contribuição de cada valor.
x̄ₚ = Σ(xᵢ · pᵢ) / Σpᵢ
Exemplo: Prova: 8 (peso 3) e Trabalho: 7 (peso 2)
x̄ₚ = (8×3 + 7×2) / (3+2) = (24+14) / 5 = 38/5 = 7,6
💡 Quando usar? Quando alguns valores são "mais importantes" que outros — notas com pesos, índices financeiros, índices de preços, etc.

📍 Mediana (x̃)

Valor do meio de um conjunto de dados ordenados. Divide os dados em duas partes iguais: 50% abaixo e 50% acima.

📐 Fórmulas

n ímpar:
x̃ = x₍₍ₙ₊₁₎/₂₎
Pega o valor da posição central.
n par:
x̃ = (x₍ₙ/₂₎ + x₍ₙ/₂₊₁₎) / 2
Média dos dois valores centrais.

💡 Exemplos

n ímpar — notas {6, 7, 8, 9, 10}, n=5:
x̃ = x₍₍₅₊₁₎/₂₎ = x₍₃₎ = 8
n par — notas {7, 8, 9, 10}, n=4:
x̃ = (x₍₂₎ + x₍₃₎) / 2 = (8+9) / 2 = 8,5
Turma A (n=10, ordenada): 3, 5, 6, 6, 6, 7, 8, 9, 10, 10:
x̃ = (x₍₅₎ + x₍₆₎) / 2 = (6+7)/2 = 6,5
Turma B (n=10, ordenada): 5, 5, 7, 7, 7, 7, 7, 7, 8, 10:
x̃ = (x₍₅₎ + x₍₆₎) / 2 = (7+7)/2 = 7,0

🛡️ Por que a mediana é especial?

Ela é especialmente útil quando os dados são assimétricos ou possuem outliers, pois não é tão influenciada por valores extremos quanto a média aritmética.
💡 Pré-requisito: os dados precisam estar ordenados (ROL) antes de calcular a mediana!

🎯 Moda (Mo)

Representa o valor (ou valores) que ocorrem com maior frequência em um conjunto de dados.

Tipos de moda

🚫 Amodal
Nenhuma moda — todos os valores aparecem a mesma quantidade de vezes
3 cabelos pretos, 3 castanhos, 3 loiros → amodal
1️⃣ Unimodal
Apenas uma moda
1 azul, 3 castanhos, 1 verde → Mo = castanho
🔢 Multimodal
Duas ou mais modas
  • Bimodal: 2 modas — Ex: {1, 2, 2, 3, 3, 4, 5}
  • Trimodal: 3 modas — Ex: {1, 2, 2, 3, 3, 4, 4, 5}

💡 Exemplos com as Turmas A e B

Turma A: 1×3, 1×5, 3×6, 1×7, 1×8, 1×9, 2×10 → Mo = 6
Turma B: 2×5, 6×7, 1×8, 1×10 → Mo = 7
💡 A moda é a única medida de tendência central que pode ser usada em dados qualitativos (ex: cor de cabelo, gênero).

⚠️ Outliers e Assimetria

🎯 Outliers

São valores que se destacam significativamente do restante do conjunto — dados atípicos ou extremos que se afastam da tendência central. Podem distorcer médias, desvios padrão e modelos preditivos.
Ex: 1.500, 2.000, 2.500, 3.000, 50.000 — o último valor é claramente um outlier.
⚠️ O que fazer com outliers? Depende do contexto. Às vezes devem ser removidos ou ajustados; às vezes são úteis para entender variações extremas ou fenômenos raros.

📊 Sequência Assimétrica

Sequência onde os dados não estão distribuídos simetricamente. A distribuição se concentra mais em um lado, criando uma "cauda" mais longa do outro lado.

📈 Assimétrica Positiva (à direita)

A cauda se estende para os valores maiores. Maioria dos dados à esquerda, poucos extremos à direita.

Ex: 1, 2, 3, 4, 5, 6, 7, 8, 18 → x̄ > x̃

📉 Assimétrica Negativa (à esquerda)

A cauda se estende para os valores menores. Maioria dos dados à direita, poucos extremos à esquerda.

Ex: 6, 12, 14, 16, 18, 20, 22 → x̄ < x̃

🧠 Regra prática

RelaçãoTipo de assimetria
x̄ > x̃Assimétrica positiva (à direita)
x̄ < x̃Assimétrica negativa (à esquerda)
x̄ = x̃Simétrica
💡 Macete: a média é "puxada" para o lado da cauda. Se a cauda é à direita (positiva), a média fica maior que a mediana.
