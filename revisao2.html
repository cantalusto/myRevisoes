📖 Estatística Descritiva

Estatística Descritiva é uma área da estatística que se concentra em resumir, organizar e apresentar os dados de forma compreensível, sem fazer inferências ou generalizações sobre uma população maior.

As técnicas ajudam a simplificar grandes volumes de dados em informações fáceis de interpretar usando medidas numéricas e gráficos.

Quando usar?

🔍 Antes de qualquer análise mais complexa
Para ter uma visão geral dos dados
📢 Comunicar resultados de uma pesquisa
Apresentar dados de forma clara e concisa
🐛 Identificar problemas nos dados
Detectar outliers ou erros de digitação

Síntese Numérica

Conjunto de medidas estatísticas para resumir e descrever dados quantitativamente. Ajudam a identificar padrões, tendências e variações sem precisar olhar valor por valor.

O que é ROL?

ROL — "Regra de Ordem Lógica": conjunto de dados de uma amostra/população disposto em ordem crescente ou decrescente. É o primeiro passo na organização de dados para análises (cálculo de mediana, quartis, construção de tabelas de frequência etc.).
Ex: dados {5, 2, 8, 1, 4} → ROL crescente: {1, 2, 4, 5, 8}

🔢 Distribuição de Frequência

Técnica usada para organizar e resumir dados em tabelas/categorias, mostrando como os valores estão distribuídos. Não faz inferência — apenas descreve.

Existem 4 tipos de frequência:

1️⃣ Frequência Absoluta (𝑓ₖ)

Definição: número total de vezes que um valor/categoria aparece no conjunto. É a contagem direta de ocorrências. O k representa a classe.

Ex: em {1, 2, 2, 2, 2, 3, 3, 3, 4, 4} → o valor 2 aparece 4 vezes → 𝑓₂ = 4
2️⃣ Frequência Relativa (𝑓ᵣₑₗ)

Definição: proporção/percentual de vezes que um valor ocorre em relação ao total de dados.

𝑓ᵣₑₗ = 𝑓ₖ / n

Onde n é o total de observações.

Ex: Notas {6,6,6,7,7,7,7,8,8,9}, n=10:
• Nota 6: 𝑓ᵣₑₗ = 3/10 = 0,30 ou 30%
• Nota 7: 𝑓ᵣₑₗ = 4/10 = 0,40 ou 40%
• Nota 8: 𝑓ᵣₑₗ = 2/10 = 0,20 ou 20%
• Nota 9: 𝑓ᵣₑₗ = 1/10 = 0,10 ou 10%
Soma = 100% ✅
3️⃣ Frequência Absoluta Acumulada (𝐹ₖ)

Definição: soma progressiva das frequências absolutas. Indica o número total de observações com valores ≤ a um valor específico.

𝐹ₖ = 𝑓ₖ + 𝐹ₖ₋₁
A última 𝐹ₖ é igual ao total de observações (n).
4️⃣ Frequência Relativa Acumulada (𝐹ᵣₑₗ)

Definição: soma progressiva das frequências relativas.

𝐹ᵣₑₗ = 𝑓ᵣₑₗ + 𝐹ᵣₑₗ₋₁
A última 𝐹ᵣₑₗ é sempre igual a 1,00 (100%).

🧮 Fórmulas Essenciais

Frequência Relativa

𝑓ᵣₑₗ = 𝑓ₖ / n

Divida a frequência absoluta pela quantidade total de dados.

Frequência Absoluta Acumulada

𝐹ₖ = 𝑓ₖ + 𝐹ₖ₋₁

Soma a frequência absoluta da classe atual com a frequência acumulada anterior.

Frequência Relativa Acumulada

𝐹ᵣₑₗ = 𝑓ᵣₑₗ + 𝐹ᵣₑₗ₋₁

Amplitude Total (𝐴ₜ) — para intervalos de classe

𝐴ₜ = 𝑉ₘₐₓ − 𝑉ₘᵢₙ

Diferença entre o maior e o menor valor do conjunto.

Tamanho da Classe (𝑇ₖ)

𝑇ₖ = 𝐴ₜ / k

Onde k é o número de classes desejado. Arredonde para cima quando necessário.

📦 Intervalo de Classe

Intervalo de classe é a amplitude/extensão de cada classe em uma distribuição de frequência. Usado quando se trabalha com dados quantitativos contínuos.

Cada intervalo possui:

📉 Limite Inferior
Valor mínimo da classe
📈 Limite Superior
Valor máximo da classe
📐 Amplitude
Limite superior − Limite inferior

⚠️ Notação importante: ⊢

O símbolo ⊢ usado nas tabelas indica:
  • Lado fechado (ex: 10 ⊢ 14): inclui o limite inferior — maior ou igual a 10
  • Lado aberto (ex: 10 ⊢ 14): exclui o limite superior — menor que 14
Ou seja, 10 ⊢ 14 significa [10, 14) — pega valores de 10 (inclusive) até menor que 14.

🛠️ Como construir uma distribuição com intervalos

1 Ordenar os dados (ROL)
2 Calcular a Amplitude Total: 𝐴ₜ = 𝑉ₘₐₓ − 𝑉ₘᵢₙ
3 Definir o número de classes (k) — geralmente dado no exercício
4 Calcular o Tamanho da Classe: 𝑇ₖ = 𝐴ₜ / k (arredonde para cima)
5 Construir a tabela: classe, 𝑓ₖ, 𝑓ᵣₑₗ, 𝐹ₖ, 𝐹ᵣₑₗ
