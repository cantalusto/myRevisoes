📖 Introdução

A estatística é a base da Ciência de Dados. Fornece ferramentas e pensamento crítico para explorar, analisar e interpretar dados.

Um projeto de Ciência de Dados depende da compreensão do problema e dos dados utilizados. É preciso explorá-los para entender o que representam e como seus valores estão distribuídos.

Como explorar os dados?

📐 Extração de medidas estatísticas
Ex: média, mediana, desvio padrão
🎨 Padrões via técnicas de visualização
Ex: gráficos, histogramas

O que é Probabilidade?

Medida numérica da chance de um evento ocorrer. Quantifica a incerteza com valor entre 0 e 1:
  • 0 evento não pode ocorrer
  • 1 evento certamente ocorrerá
💡 Dica: Probabilidade quantifica incerteza; Estatística analisa dados observados. Andam juntas.

🧠 Inferência Estatística

Processo de fazer conclusões/generalizações sobre uma população com base em uma amostra. Usa-se uma amostra representativa para estimar características ou testar hipóteses sobre toda a população.

Os 3 tipos — memorize bem!

1️⃣ Inferência Dedutiva — do geral para o específico

Parte de premissas gerais para chegar a conclusões específicas e necessariamente verdadeiras (se as premissas forem verdadeiras).

• Premissa 1: Todos os mamíferos têm pulmões.
• Premissa 2: Uma baleia é um mamífero.
• Conclusão: Logo, uma baleia tem pulmões. ✅
2️⃣ Inferência Indutiva — do específico para o geral

Parte de observações específicas para formar generalizações prováveis. Não garante certeza, mas sugere padrões. Indicada para prever padrões futuros.

• Observação: Todos os cisnes que observei são brancos.
• Conclusão: Provavelmente, todos os cisnes são brancos. 🤔
3️⃣ Inferência Abdutiva — melhor explicação

Escolhe a explicação mais provável para um conjunto de fatos. Indicada para hipóteses ou diagnósticos.

• Evidência: O chão está molhado.
• Conclusão provável: Deve ter chovido. 🌧️

Conceitos relacionados

Dedução: raciocínio do geral → específico, garante verdade se premissas são verdadeiras.
Indução: raciocínio do particular → geral, infere o "todo" a partir de uma parte.
Generalização: derivar princípios amplos a partir de casos específicos.
Métodos Estatísticos: técnicas para coletar, organizar, analisar e interpretar dados.
💡 Macete: Dedutiva = Desce do geral. Indutiva = sobe a partir de exemplos. Abdutiva = busca a melhor hipótese.

👥 Categorias de Dados Quanto à Abrangência

Refere-se ao escopo do conjunto analisado em relação à população de interesse.

📊 Dados Populacionais

  • Representam todos os indivíduos/elementos
  • Abrangentes — refletem o conjunto completo
Ex: A idade de todos os habitantes de uma cidade.

🎯 Dados Amostrais

  • Representam uma parte (subconjunto) da população
  • Usados para estimar/inferir características da população
Ex: A idade de 500 habitantes selecionados aleatoriamente.
💡 Quando uma análise da população inteira é impraticável, usamos uma amostra representativa e fazemos inferência estatística.

📏 Escalas de Medidas

Segundo STEVENS (1946), atributos podem ser:

Qualitativos / Categóricos: valores não numéricos (palavras, símbolos)
Quantitativos / Numéricos: valores numéricos — mais fáceis de manipular

Existem 4 tipos principais de escalas, em ordem crescente de poder:

1. Escala Nominal — só categoriza

Forma mais simples. Categoriza/classifica sem ordem ou hierarquia. Não há relação quantitativa.

Exemplos: Gênero (masculino, feminino), Cores (azul, vermelho), Tipo de produto.

Operações permitidas: apenas contagem (frequência) e comparação de igualdade.

2. Escala Ordinal — categoriza + ordena

Tem ordem/hierarquia, mas as distâncias entre categorias não são iguais nem mensuráveis.

Exemplos: Satisfação (muito satisfeito > satisfeito > insatisfeito), Posição (1º, 2º, 3º), Escolaridade (fundamental, médio, superior).

Operações: contagem, ordenação, comparação maior/menor.

⚠️ Não dá para afirmar que a diferença "muito satisfeito → satisfeito" é igual a "satisfeito → insatisfeito".
3. Escala Intervalar — ordena + distâncias iguais (sem zero absoluto)

Tem ordem e distâncias iguais, mas não tem zero absoluto (o zero não significa ausência total).

Exemplos: Temperatura em °C/°F (0°C ≠ ausência de temperatura); Ano de nascimento (ano 0 ≠ ausência de tempo).

Operações: contagem, ordenação, soma e subtração, média, desvio padrão.

⚠️ NÃO faz sentido dizer "20°C é o dobro de 10°C" (multiplicação/divisão sem significado).
4. Escala Razão — a mais completa (com zero absoluto)

Tem todas as propriedades anteriores + zero absoluto (zero = ausência total). Permite razões/proporções.

Exemplos: Peso (0 kg = ausência; 80 kg é o dobro de 40 kg), Altura, Idade.

Operações: todas — soma, subtração, multiplicação, divisão, razões.

🔢 Tipos Numéricos

Categorias de variáveis quantitativas. Dividem-se em duas:

🔹 Variáveis Discretas

Definição: valores finitos ou contáveis. Não há intermediários entre dois consecutivos.

Natureza: Contagem

Exemplos:

  • Número de alunos em uma sala
  • Número de carros em um estacionamento
  • Quantidade de erros em um software

🔸 Variáveis Contínuas

Definição: qualquer valor dentro de um intervalo (frações, decimais). Infinitos valores possíveis entre dois pontos.

Natureza: Medição

Exemplos:

  • Peso de uma pessoa (70,5 kg)
  • Altura de uma planta (1,75 m)
  • Temperatura (25,3°C)
💡 Macete: Discreta = você conta (1, 2, 3...). Contínua = você mede (1,5; 1,55; 1,555...).
